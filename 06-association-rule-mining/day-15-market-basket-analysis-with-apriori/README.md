# Day 15 — Market Basket Analysis with Apriori

## Overview
Performs market-basket analysis on grocery transactions with Apriori, frequent-itemset mining and association-rule measures such as support, confidence and lift.

## Learning objectives
- Understand the problem and the structure of the supplied dataset.
- Prepare and inspect data using appropriate Python tools.
- Implement the analytical or machine-learning techniques explored in the notebook.
- Interpret outputs and evaluation measures rather than relying only on model execution.

## Concepts and techniques
Python, Pandas, mlxtend, Pandas, NumPy

## Project contents
- `day-15.ipynb` — original course notebook, preserved from the supplied archive.
- `data/` — dataset files identified as relevant to this assignment.
- `reference/` — assignment brief, when one was present in the supplied archive.

## Run the notebook
1. Create and activate a Python virtual environment.
2. Install the repository dependencies from the root `requirements.txt`.
3. Start Jupyter Notebook or JupyterLab from the repository root.
4. Open `day-15.ipynb`.
5. Run the cells in order. If the notebook expects a different relative data path, update the working directory or path locally.

## Notes and limitations
- The source notebook uses a minimum support threshold around 0.02 and explores association-rule metrics. Results depend on the supplied transaction data and parameter choices.

- The notebook is retained as source material; no unverified model scores or performance claims are added here.
- Check dataset provenance, licensing and privacy before publishing this repository publicly.
