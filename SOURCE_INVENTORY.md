# Source Inventory

This repository was assembled from the two supplied ZIP archives:

- `assign(1).zip`
- `assignments(1).zip`

## Inclusion and exclusion

- Included: the 15 daily assignment notebooks (Days 1–15), their identified datasets, and available PDF assignment briefs.
- Excluded: the separate Hypothyroid Classification project (the 16th project), including its notebook, data, model artifact and project brief.
- Excluded: Jupyter `.ipynb_checkpoints` copies and duplicate checkpoint files.
- Unmapped auxiliary files that appeared potentially relevant were retained under `supporting-files/` rather than assigned to a day without evidence.

## Dataset handling

- Data files were copied into the relevant assignment folders so each exercise can be run independently.
- The Day 7–12 source notebooks and briefs have inconsistent day-specific dataset naming; see the root README and each affected assignment README.
- Day 13 and Day 14 Iris CSV copies were identical in the source archives; each assignment has its own copy.

## Integrity and review

- Original notebook source was copied without code edits.
- File names and directory placement were normalized for repository readability.
- Before public publication, review dataset redistribution permissions, personal information, credentials and any embedded outputs.
